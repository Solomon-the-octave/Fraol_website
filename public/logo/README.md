# Logo files

| File                      | What it is                                   | Used for                                   |
|---------------------------|----------------------------------------------|--------------------------------------------|
| `fraol-icon.png`         | Cow mark, forest green `#1E3A2F`, transparent | Nav bar on the solid white bar, favicon    |
| `fraol-icon-light.png`   | Same mark in white, transparent               | Nav bar while it sits over a dark header   |

The nav renders the **symbol only** and sets "FRAOL / Smart Agribusiness PLC"
beside it in Poppins. The delivered artwork has "JANKA FARMS" set inside the
lockup, so the mark is used on its own until a lockup carrying the new name
arrives.

## ⚠️ These are interim files

Both PNGs were extracted from a screenshot of the brand board, not from a
source asset. They are clean enough to work at nav and favicon size but the
edges are soft and there is no vector version.

**Replace before launch** with the designer's real files:

- [ ] Cow mark as SVG (or a PNG at 512px or larger, transparent background)
- [ ] Full lockup carrying the new name, if one is produced
- [ ] A reversed or white version, if the designer supplies one rather than a
      recolour

Drop the replacements in at the same filenames and nothing else needs changing.
A missing file is handled: the nav probes the image and falls back to the type
lockup alone rather than showing a broken-image box.
